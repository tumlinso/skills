# Retired CUDA controller v0

This archive preserves the controller implementation and controller-dependent test sources from the source commit recorded in manifest.json. The archived Python files are deliberately named so pytest and unittest default discovery do not collect the retired tests. They are historical source, not an execution fallback. The active cuda/scripts/cuda_controller.py is a fail-closed tombstone; host work belongs to Device Scheduler as described in references/execution/host-execution.md.
